# Разбор заемщика

Статический веб-инструмент для первичной сортировки пакета документов и подготовки книги Excel для специалиста по кредитному анализу.

## Запуск

Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## Что делает

- принимает пачку файлов или папку;
- классифицирует документы по названию, пути и извлечённому тексту;
- извлекает кандидаты на ИНН, КПП, ОГРН, период и денежные суммы;
- формирует книгу Excel: обзор, реестр документов, сводка по типам и контрольный список;
- позволяет аналитику заполнить комментарии и статус проверки в Excel.

Поддерживаются PDF с текстовым слоем, DOCX, XLS/XLSX, XML, TXT, CSV и RTF. Изображения и сканированные PDF отображаются в реестре, но для извлечения текста им нужен OCR. Старый формат DOC показывается в реестре, но содержимое автоматически не читается.

## Конфиденциальность и ограничения

Чтение файлов и создание книги выполняются в браузере на устройстве пользователя. Документы не отправляются приложением на сервер. Для загрузки библиотек используются CDN, а для публикации — GitHub Pages. Не загружайте в публичный репозиторий документы заемщиков или результаты анализа.

Результаты распознавания — неподтверждённые кандидаты, а не проверенные факты. Сверяйте все реквизиты, суммы, периоды и классификацию с первоисточниками. Инструмент не рассчитывает кредитоспособность, не выставляет рейтинг, не рекомендует одобрение или отказ и не заменяет действующие методики и профессиональное суждение.

## Примеры исходного процесса

В предоставленной папке «Автоматизация» обнаружены методики анализа юрлиц и физлиц, шаблоны финансового анализа, финансовая и налоговая отчётность, банковские справки, карточки счетов 60/62, договоры, ТЭО, БКИ и документы поручителей. Эти материалы использованы только для проектирования категорий. В репозиторий не включены исходные документы, персональные данные, реквизиты заемщика или заполненные шаблоны.
