# Анализ заемщика — рабочее место аналитика

Статичный сайт (GitHub Pages) без сервера и сборки. Загружаете любые документы по заемщику (папка, файлы, ZIP) — приложение в браузере находит периоды и суммы отчетности, реквизиты, и собирает книгу Excel «фин анализ» с живыми формулами по Методике оценки финансового положения ЮЛ (14.08.2025) с Изменениями № 1 (01.06.2026).

Документы и введенные данные никуда не отправляются и не сохраняются.

## Что читается

| Формат | Что берется |
|---|---|
| XLSX/XLS/CSV | таблицы баланса и отчета о финрезультатах (периоды в заголовках: «I кв. 2016г.», «за 9 месяцев 2025», даты, годы), единицы измерения |
| PDF с текстом | строки по кодам форм 1 и 2, реквизиты |
| DOCX | таблицы и текст |
| ZIP | рекурсивно |
| TXT/RTF/XML/старый DOC | только текст: реквизиты (ИНН с проверкой контрольной суммы, ОГРН, ОКВЭД, дата регистрации, наименование) |
| сканы, изображения | попадают в реестр с пометкой «нужен ручной ввод» (OCR нет) |

Единицы нормализуются в тыс. руб. Расходы формы 2 хранятся со знаком «минус». Значения из «текущего» столбца отчета важнее сравнительных; расхождения между документами выводятся на лист «Проверки».

## Книга Excel

Сводка · Актив · Пассив · Приб_Уб (нарастающим итогом + по кварталам) · Удельный вес в ВБ · Изм.стр. Ф1 / Ф2 (к аналогичному периоду прошлого года) · Чистые активы · Коэффициенты · Фин показ (баллы, класс) · Нефин показат (12 факторов) · Фин состояние (негативные явления п. 7.2, матрица п. 7.4) · графики · СПРАВОЧНИК (пороги) · Проверки · Источники · Документы.

Все расчеты — формулы; периоды выровнены по колонкам D, E, … на всех листах. Синий шрифт — данные из документов, желтая заливка — нужен ввод, оранжевая — допущение или автоподстановка. Значения формул сохранены в файле (корректно открывается в режиме защищенного просмотра и на телефоне).

### Автоматически

* отрасль — по ОКВЭД (45–47 торговля, 41–43 строительство, 05–33 и 35 промышленность, остальное — прочее);
* показатель 6 бизнес-риска (длительность работы) — по дате регистрации; показатель 12 (ликвидация) — по чистым активам против уставного капитала;
* негативные явления 7.2.1–7.2.5, 7.2.11, 7.2.12;
* баланс «на начало периода» — конец прошлого года; если его нет — конец периода (оранжевые ячейки).

### Вручную (в документах этого нет)

Оценки бизнес-риска 1–5, 7–11; негативные явления 7.2.6–7.2.10; признак банкротства. Расшифровки 5445, 5540, 5320 для Кл при отсутствии принимаются равными 0 (с пометкой).

## Методические решения

* Кпл считается в **месяцах** (выручка / Т, Т = 3, 6, 9, 12): пороги 4 и 8 рассчитаны на месяцы.
* Коб и Кобдз — по средним остаткам и приводятся к году ×12/Т (п. 5.1.4).
* Рпр для «Прочего»: методика не определяет интервал 10,9…12,7% — принято 5 баллов (консервативно).
* Матрица п. 7.4 допускает «хорошее» положение при одном негативном явлении (2 класс), п. 7.2 — нет: в итоге показывается «среднее» с предупреждением.
* Чистые активы: 1600 − (1400 + 1500 − 1530).

## Файлы

`index.html`, `styles.css`, `app.js` (интерфейс) · `model.js` (справочники, периоды, реквизиты) · `importers.js` (чтение файлов) · `merge.js` (слияние) · `export.js`, `export2.js` (листы книги) · `xw.js` (генератор XLSX и вычислитель формул, без внешних библиотек) · `sw.js`, `manifest.webmanifest`.

Внешние библиотеки (CDN): SheetJS (чтение XLSX/XLS), pdf.js (PDF), JSZip (DOCX, ZIP).

Приложение — инструмент подготовки материалов. Результат предварительный и требует профессионального суждения аналитика.
